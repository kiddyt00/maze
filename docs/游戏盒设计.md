# TrailStory 游戏盒 · 设计文档

> 本仓库原本是单游戏工程《重力迷宫》，现已改造为**游戏合集**：
> 一个 App（游戏盒）承载多个子游戏，迷宫退居为子游戏之一，跟读训练作为第二个子游戏接入。

---

## 一、工程架构（游戏合集）

### 1.1 身份不变原则

| 项 | 值 | 说明 |
|---|---|---|
| bundleName | `com.trailstory.mazeball` | **保持不变** |
| App 显示名 | `TrailStory 游戏盒` | 改了 label，不影响签名 |
| 签名 | AGC 调试证书 `maze.cer` + `maze-debugDebug.p7b` | **继续复用，无需重新申请** |

> 改 `bundleName` 等于换一个 App：必须在 AGC 重新建应用、重新出证书和 Profile。
> 因此合集化阶段**不动 bundleName**，只改显示名与页面结构。

### 1.2 目录结构

```
entry/src/main/ets/
├── entryability/EntryAbility.ets   # 入口, 加载 pages/Lobby
├── pages/                          # 所有可路由页面 (必须在 main_pages.json 注册)
│   ├── Lobby.ets                   # 游戏大厅 = 合集首页
│   ├── MazeGame.ets                # 子游戏 1: 重力迷宫
│   └── ReadGame.ets                # 子游戏 2: 跟读乐园
├── games/                          # 子游戏的非页面逻辑, 按游戏分子目录
│   ├── maze/
│   │   ├── MazeGen.ets             # 递归回溯生成迷宫
│   │   └── SceneBuilder.ets        # ArkGraphics3D 场景构建
│   └── read/
│       └── Content.ets             # 跟读内容库 (中文馆 / English)
└── common/
    └── Speech.ets                  # TTS 封装 (标准音)
```

### 1.3 新增一个子游戏

1. `pages/` 下新建页面（`@Entry @Component`）；
2. `resources/base/profile/main_pages.json` 的 `src` 里注册页面路径；
3. `pages/Lobby.ets` 的 `GAMES` 数组里加一条（emoji / 名称 / 描述 / 路由 / 是否就绪）；
4. 需要跨页面复用的逻辑放到 `games/<name>/`。

## 二、跟读乐园 · 交互设计 v0.2

### 2.1 前提约束（来自产品需求）

- 使用者是**还不识字的小朋友** → **孩子端零文字依赖**，必须"语音 + 图形"驱动；
- 需要**跟读 + 读音评分 + 可重复的引导练习**；
- 内容范围：中文（颜色 / 简单物体 / 动物 / 数字 / 古诗词 / **汉字启蒙**）+ 英文（数字 / 颜色 / 动物 / 简单物体 / **字母启蒙**）；
- 需要**接入 LLM 做交互**。

### 2.2 设计原则

| 原则 | 落地 |
|---|---|
| 永远正向 | 不出现"错 / 失败 / 0 分"，最低档也是"没关系，跟着我慢慢读" |
| 绝不卡关 | 同一题最多 4 轮，第 4 轮无论结果都过关并标记"需复习" |
| 大触控目标 | 所有可点元素 ≥ 80dp，主按钮更长 |
| 多感官 | 看图 + 听音 + 跟读 + 得分动画 |
| 即时反馈 | 每次操作 ≤ 1.5s 内有声/有形回应 |

### 2.3 孩子端界面分层

| 层 | 面向 | 呈现 |
|---|---|---|
| L1 主界面 | 孩子 | **零文字**：大图标卡片 + 图形化主题，进入自动语音播报 |
| L2 进度 | 孩子 | 星星 / 贴纸图鉴 / 成长伙伴（纯图形） |
| L3 家长中心 | 家长 | 文字报告与设置，进入需长按或简单算术门 |

### 2.4 核心闭环状态机

```
①待跟读 ──> ②录音中 ──> ③评分中 ──> ④结果反馈 ──> ⑤递进式引导复练
   │           │            │             │                │
自动播标准音  静音1.2s自动停  ≤1.5s    大分数+星级      最多4轮, 绝不卡住
```

- **静音 1.2s 自动停止录音**：比"再点一次按钮"更贴合低龄儿童；
- 结果页：大分数 + 星级 + 逐字高亮（对的绿 / 需注意的橙）+ 原音与自己的录音对比回放。

### 2.5 评分方案（重要：系统无发音评测 API）

实测本地 SDK（API 26）：`@kit.CoreSpeechKit` 只提供**语音识别**与**语音合成**，
`SpeechRecognitionResult` 仅有 `{isFinal, isLast, result}`，
**不存在声调 / 音素级的发音评测 API**。因此评分自建为三级：

| 级 | 做法 | 能给出 | 依赖 |
|---|---|---|---|
| L1 必做 | ASR 文本 vs 目标文本（汉字/pinyin 归一化比对） | 完整度、正确度（读对/漏字/多字） | 离线 |
| L2 必做 | 把 ASR 结果 + 目标 + 耗时交给端侧 LLM 判定并生成点评 | 流利度评价 + 具体注意点 | 离线 |
| L3 可选 | 接入云侧专业发音评测 SDK | 声调 / 音素级精度 | 联网 + 账号 |

综合得分 = **完整度 40% + 正确度 40% + 流利度 20%**，再映射到 4 档正向星级：

| 得分 | 星级 | 话术 |
|---|---|---|
| ≥ 90 | ⭐⭐⭐ | 太棒了！ |
| 70–89 | ⭐⭐ | 很好！再标准一点点 |
| 50–69 | ⭐ | 快对了！再来一次 |
| < 50 | ⭐ | 没关系，跟着我慢慢读 |

### 2.6 递进式引导复练（核心差异化）

| 轮次 | 引导手段 |
|---|---|
| 第 1 轮 | 慢速示范（约 0.7x）+ 逐字拆读 + 口型动画 |
| 第 2 轮 | 逐音节跟读，读对一个打一个勾 |
| 第 3 轮 | 首音提示跟读（给出起始音） |
| 第 4 轮 | **无论结果都过关**，标记"需复习"进入间隔重复队列 |

### 2.7 AI 伙伴（LLM 交互）

| 模式 | 触发 | 作用 |
|---|---|---|
| 引导模式（默认） | 进入任一练习 | 用说话带孩子走完流程 |
| 陪聊模式 | 点"聊天" | 自由对话（内容安全过滤） |
| 出题模式 | 点"考考我" | 按孩子兴趣动态生成跟读题 |
| 故事模式 | 点"听故事" | 互动故事，中途提问 |

**架构决策：LLM 只当"语言层"，不当"教学大脑"。**

| 交给确定性逻辑（本地规则/数据） | 交给 LLM（生成） |
|---|---|
| 学什么、评分、进度、脚手架第几步、复习队列 | 鼓励话术、拆解引导、陪聊、按兴趣出题 |

> 理由：教学正确性与"绝不卡关"必须可预测、可测试；只有语言表达需要 LLM 的灵活性。
> 这样可以彻底避免模型幻觉污染教学内容。

**儿童安全（必做）**：锁定角色的系统提示词 + 输出过 `@hms.security.safetyDetect` + 敏感话题温柔重定向 + 家长可查对话记录。端侧运行则对话数据不出设备。

## 三、技术底牌（本地 SDK 实测结论）

| 能力 | SDK 现状 | 结论 |
|---|---|---|
| 语音识别 ASR | `@kit.CoreSpeechKit` → `@hms.ai.speechRecognizer` | 可用 |
| 语音合成 TTS | `@hms.ai.textToSpeech`（离线 `online:1`；中文音色 13/0，英文 8） | **已接入** |
| 逐音素发音评测 | **无** | 需自建（见 2.5） |
| 端侧大模型 | `@hms.data.localChatModel`（API 20+，`init()` 后 `chat()`） | 优先方案 |
| 内容安全 | `@hms.security.safetyDetect` | 对话过滤 |
| 3D 渲染 | `@kit.ArkGraphics3D` + `Component3D` | 迷宫已用 |

> 找 Kit 时务必**两处都查**：`$SDK/default/openharmony/ets/{api,kits}` 与 `$SDK/default/hms/ets/{api,kits}`
> —— 语音与端侧 AI 全部在 `hms/` 下，只看 `openharmony/` 会误判为"没有能力"。
