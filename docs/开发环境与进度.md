## 一、环境

- **SDK**: HarmonyOS Command Line Tools 26.0.0.851，解压在仓库同级目录 `.harmonyos-tools/`。
  不需要 DevEco Studio。
- **关键环境变量**（必须设置，否则 hvigor 找不到 SDK）:

  ```
  DEVECO_SDK_HOME=<仓库同级>/.harmonyos-tools/command-line-tools/sdk
  ```

- **SDK 真实路径比想象多一层 `default/`**：
  - HMS 接口：`$DEVECO_SDK_HOME/default/hms/ets/api/`
  - OpenHarmony 接口：`$DEVECO_SDK_HOME/default/openharmony/ets/api/`

  查接口签名直接去这两个目录 grep，比查文档快。

- `build-profile.json5` 里 storePassword/keyPassword 是 **36 字符**（AGC 要求 ≥32）。

## 四、真机调试（踩过的坑）

设备：HUAWEI Mate 70 (CLS-AL00)，HarmonyOS 6.1.1 = **API 24**，USB 调试。`hdc` 在 `~/.local/bin/hdc`。

```bash
export PATH=$PATH:/home/kiddyt00/.local/bin
hdc list targets
hdc uninstall com.trailstory.mazeball      # 必须！
hdc install harmonyos-maze/entry/build/default/outputs/default/entry-default-signed.hap
hdc shell "power-shell wakeup; aa start -a EntryAbility -b com.trailstory.mazeball"
hdc shell "aa dump -l" | grep mazeball     # 确认真的在前台
```

四个必须记住的点：

1. **安装前一定要先 `uninstall`**。直接 `install -r` 会报
   `code:9568332 error: install sign info inconsistent`（旧安装签名不一致）。
2. **锁屏时 `aa start` 会失败**：`Error Code:10106102 ... The device screen is locked during the application launch`。
   但 `snapshot_display` **依然返回成功，并且拍到的全是锁屏壁纸** —— 极易误判成"渲染正常"。
   **任何截屏结论之前，先 `aa dump -l | grep mazeball` 确认应用在前台。**
3. **`power-shell wakeup` 和 `aa start` 必须写在同一条 `hdc shell` 命令里**（用 `;` 连接）。
   分成两条执行时，`wakeup` 之后屏幕停在锁屏，`aa start` 仍然被拒。
4. `power-shell timeout -o 1800000` 把息屏时间改成 30 分钟，否则约 24 秒就息屏。

其它常用命令：

```bash
hdc shell uinput -T -c X Y                                     # 点击
hdc shell snapshot_display -f /data/local/tmp/x.jpeg
hdc file recv /data/local/tmp/x.jpeg /tmp/x.jpeg               # 取回截图
hdc shell hilog -x | grep -E "KidsRead|GameBox|MazeDebug"      # 看日志
```

截图 1216×2688，密度约 3.25 px/vp。已标定的点击坐标：

| 位置 | 坐标 |
| --- | --- |
| 大厅 · 重力迷宫（左卡） | (328, 1075) |
| 大厅 · 跟读乐园（右卡） | (912, 1075) |
| 迷宫页 · 「‹ 返回大厅」 | (150, 161) |

5. **Canvas 的 `fillText` 不渲染 emoji**：在 Canvas 上画 emoji 会静默空白。
   迷宫里的玩家/终点因此改用叠加的 `Text` 组件，坐标由 Canvas 算好后存进 `@State` 定位。
6. **`uitest dumpLayout` 看不到 Canvas 内容**：Canvas 里画的东西在层级转储里完全不存在，
   验证只能靠 `snapshot_display` 截图 + 像素取色（例如迷宫地板色 `#fff8e7` 的像素范围）。
7. **键盘方向键无法用 `uinput` 模拟**：没有 keyevent 能力，迷宫只能靠屏幕方向键按钮验证。

> `aa force-stop` + `aa start` **不等于冷启动** —— 应用会恢复上次停留的页面。
> 要真正回到首屏，`uninstall` + `install` 最省事，或者用页面内的返回按钮逐级退出。

## 六、两条重要的技术限制

1. **SDK 里没有拼音 / 发音评测接口**。全量 grep 过 `pronunciation`、`pronounce`、
   `speechEvaluat`、`assessment`、`ScoreInfo`、`pinyin` 都没有。
   所以评分只能靠"识别文字 + 与目标文本比对"，这也正是 `Score.ets` 里要放
   47 组同音字表的原因（小朋友读对了但引擎写成别的同音字，不该扣分）。

   > **未验证的改进线索**：`@ohos.i18n` 导出了 `Transliterator`
   > （`@ohos.i18n.d.ts:1932`，`getAvailableIDs()` / `getInstance(id)` / `transform(text)`），
   > ICU 的 `Han-Latin` 转换器有可能能拿到汉字拼音。**如果能跑通，评分准确度会大幅提升**，
   > 值得回家里先花十分钟试一下。

2. **`speechRecognizer` 只支持中文离线**（官方文档明确 only `zh-CN`）。
   所以英文跟读目前只给"读完了，真棒"的鼓励分，不做正确度断言
   （`Score.ets` 里 `scored: false`）。
   `writeAudio` 每次只接受 **640 或 1280 字节**，总音频上限 60 秒。

## 七·B、数据与生成脚本

两个仓库的原始数据是浏览器脚本（`window.MAZES_DATA` / `window.MAP_DATA`），
已预转换为 `resources/rawfile/` 下的 JSON，运行时不解析 JS：

| 数据 | 来源 | 转换脚本 | 产物 |
| --- | --- | --- | --- |
| 奇妙迷宫 99 关 | kids-maze-game `js/mazes-data.js` + `levels-catalog.js` | `tools/build-maze-levels.mjs` | `rawfile/maze/levels.json`（195KB） |
| 拼拼中国地图 | kids-games `games/puzzle/data/*.js` | `tools/build-map-data.mjs` | `rawfile/map/`（28 份，3.2MB） |

```bash
cd harmonyos-maze
node tools/build-maze-levels.mjs   # 需要同级目录有 kids-maze-game 的克隆
node tools/build-map-data.mjs      # 需要同级目录有 kids-games 的克隆
```

> 想换地图/关卡就改脚本里的源路径重跑，不要手改 JSON。
